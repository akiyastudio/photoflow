# 素材导入与整理

## 从 SD 卡导入

1. 在首页点击“从 SD 卡导入媒体”，或在项目空白处选择“导入 → 从 SD 卡导入”。
2. 选择一个或多个已记录盘符。
3. 为每个盘符指定“工作文件”或“花絮”。
4. 确认本次是否删除来源文件。
5. 开始导入并等待任务完成。

导入期间不要拔出存储卡。即使点击取消，也应等待界面显示已取消或已完成后再断开设备。

## 导入后的目录

工作素材会按媒体类型整理到项目目录，例如：

- `raw`：相机 RAW 文件。
- `jpg`：普通图片或 RAW 配套 JPG。
- `mov`：视频素材。
- 花絮目录：按花絮导入流程保存的素材。

具体目录会根据导入内容和当前版本的工作流生成，不要在导入过程中手工移动临时文件。

## 保留还是删除源文件

“导入后默认删除源文件”只决定初始值；每次导入面板仍可单独选择。

- 关闭：复制素材，来源保留。适合首次使用和重要素材。
- 开启：只有所有文件复制并校验成功后，软件才处理来源媒体。

即使开启了校验，也应在格式化 SD 卡前检查目标项目中的文件数量、大小和可打开性，并确认独立备份已经完成。

## 导入时的视频处理

- 工作文件和花絮分别设置是否在导入时执行视频切割、视频转码；两类素材共用视频切割和视频转码面板中保存的功能参数。

## 导入底片、花絮和普通文件

在项目空白区域打开菜单，选择“导入”：

- **导入底片**：把底片或扫描素材纳入项目。
- **导入花絮**：选择文件或文件夹，并决定是否删除来源。
- **导入进度**：把已有后期文件夹登记为进度。
- **导入文件**：把普通文件复制或移动到当前目录。

## 断连和失败处理

批量导入时，如果某张卡断连，已完成的暂存文件会保留；重新插卡后可以继续。遇到磁盘空间不足、权限错误或来源断连时，先处理原因，再从任务提示恢复或重试。
