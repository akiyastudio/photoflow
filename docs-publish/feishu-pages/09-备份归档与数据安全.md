# 备份、归档与数据安全

## 项目备份

开发版支持把项目文件、版本关系和软件设置保存为历史快照。备份目标可以是本地磁盘或 NAS。

1. 从首页点击“设置备份”，或进入“设置 → 存储”。
2. 开启备份并选择目标类型与位置。
3. 选择历史备份模式和保留策略。
4. 根据需要开启每日自动备份和导入后备份。
5. 点击“立即备份”，等待任务完成。

首页会显示上次成功时间、正在备份、备份盘未连接或需要处理等状态。

## 从备份恢复

首次选择工作文件夹时，或在备份设置中检查备份位置：

1. 选择包含完整快照的备份位置。
2. 查看快照时间、项目数量和大小。
3. 选择目标工作文件夹。
4. 开始恢复并等待完成。
5. 抽查项目、版本关系和设置。

不要把恢复目标指向仍包含未备份新文件的工作目录，避免产生难以判断的冲突。

## 项目归档

归档用于把已完成项目移动到其他磁盘或长期存储位置。启用前在“设置 → 存储”选择归档目标。

- 归档前确认交付完成、版本关系稳定且备份成功。
- 归档任务完成前不要断开来源或目标磁盘。
- 归档后抽查文件数量、大小和关键媒体。
- “已归档”是项目状态；实际文件是否已移动到归档盘取决于是否执行了归档任务。

## 缓存和数据

缩略图、视频预览和数据库位于应用数据或配置的缓存目录，不污染客户项目目录。可以设置缓存容量和自动清理策略。清理缓存通常不会删除项目原片，但会导致再次浏览时重新生成预览。

## 文件删除和恢复

- Windows 删除操作优先进入系统回收站。
- 撤销操作会检查文件身份，避免同一路径出现新文件后误删或误覆盖。
- 数据库只记录恢复所需的轻量信息，不保存被删除媒体的完整副本。

## 必须保留独立备份

软件保护无法覆盖磁盘损坏、勒索软件、同步冲突、误格式化、NAS 故障和长期静默损坏。建议至少保留：工作盘、独立备份盘，以及不长期在线的第二份备份。
