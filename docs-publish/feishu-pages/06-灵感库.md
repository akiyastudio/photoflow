# 灵感库

灵感库用于集中收集拍摄参考、场景、造型、构图、灯光和其他创作素材。它使用普通本地文件夹，不会把素材复制进项目数据库。

## 第一次设置

1. 从首页进入“灵感库”。
2. 选择用于收集和整理灵感素材的根文件夹。
3. 软件读取目录树并以独立标签打开灵感库。

可在“设置 → 界面”中固定灵感库根页面，防止误关闭。

## 整理素材

灵感库支持与项目文件浏览器相同的基本操作：

- 新建和导入文件或文件夹。
- 重命名、剪切、复制、粘贴和删除。
- 图标 / 列表模式、排序、搜索和筛选。
- 展开目录树并快速进入子文件夹。
- 查看预览和详细信息。

## 增加到项目

1. 选择一个或多个灵感文件，或在目录树中选择文件夹。
2. 点击“增加到项目”。
3. 选择目标项目。
4. 素材会增加到目标项目的“策划”文件夹。

如果有多个项目，软件会记住最近使用的目标，也可以选择其他项目。快捷方式解析出的外部内容按只读方式处理，避免误移动外部目录。

## 使用建议

- 按“场景、风格、构图、光线、服装、道具”等建立一级目录。
- 不要把客户正式交付文件放入灵感库；它适合参考素材而不是项目归档。
- 灵感库应纳入独立备份。软件的项目备份是否包含它取决于当前存储配置和备份范围。
