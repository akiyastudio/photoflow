# 文件浏览、选片与后期版本

## 文件浏览器

项目和灵感库使用统一的文件浏览工作区，支持：

- 图标模式和列表模式。
- 按文件名、修改日期或大小排序。
- 搜索与筛选。
- 最近文件、前进、后退和面包屑导航。
- 单选、多选、框选以及键盘辅助选择。
- 新建文件夹或使用 Windows 已注册的“新建文件类型”。
- 复制、剪切、粘贴、重命名、删除和查看详细信息。

图片、RAW 和视频可以预览；文件详情面板显示类型、尺寸、时间和可用的技术元数据。可在“设置 → 界面”中选择单击或双击打开。

## 喜欢与星级

照片流直接读写图片自身的 XMP 星级。界面可以显示为“喜欢 / 不喜欢”，也可以显示一星到五星。

- 喜欢模式会把任意星级视为喜欢。
- 在喜欢模式点击喜欢时，会写入五星。
- 项目顶部可以集中查看喜欢的图片。

## 手动选片

1. 在项目中明确选择一个来源文件夹或媒体文件。
2. 点击工具栏“选片”，或在右键菜单选择“选片”。
3. 确认来源后执行。

输出文件夹位于来源文件夹同级，名称为“来源文件夹名_选片”。再次对同一来源选片会复用已有选片节点，并增量复制不存在的文件；已有目标文件不会被覆盖。

## 从文件名选片

1. 点击“从文件名选片”。
2. 明确选择图片、视频或混合媒体来源文件夹。
3. 粘贴客户提供的文件名、编号或清单。
4. 预览匹配结果并开始整理。
5. 查看成功、已存在、未支持或冲突项目。

不要依赖项目根目录作为隐式来源；当前版本要求用户明确选择来源文件夹。

## 建立后期进度

在项目空白处选择“新建 → 新建进度”，或者“导入 → 导入进度”。普通项目内文件夹也可以登记为版本节点。

主分支进度可以配置：

- 是否启用图片跟踪。
- 是否沿用上一版本文件名。
- 是否从父版本补齐缺失媒体。

选片属于附属分支，不参与主版本传播，也不能作为新主版本的直接父节点。

## 版本状态

- **原始素材**：最初的来源节点。
- **未跟踪**：尚未建立媒体关系。
- **跟踪处理中**：正在比较、等待确认或提交。
- **已跟踪**：最近一次确认已提交。
- **待刷新**：文件变化后需要重新比较。
- **需要修复**：提交不完整或发生异常，需要进入修复流程。

## 确认跟踪结果

比较完成后打开确认面板，逐项检查识别结果、新素材和缺失引用。存在“等待确认”或“缺少引用”的项目时，不能提交。可以使用并排或叠加方式比较版本，调整决定后再确认提交。
