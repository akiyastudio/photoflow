# 照片流文档发布包

本目录用于把“照片流 PhotoFlow”的产品介绍和使用教程发布到飞书。

## 推荐发布方式

1. 优先导入 `照片流-用户手册.docx`。DOCX 已嵌入开发版界面截图，适合作为一篇完整的飞书在线文档。
2. 如果要建设飞书知识库，请按 `feishu-pages` 中的编号逐篇导入 Markdown，并按照编号建立页面树。
3. 导入后检查标题层级、图片宽度、提示框和代码块，再设置知识库成员及分享范围。

## 建议的飞书知识库目录

1. 产品介绍
2. 安装与首次启动
3. 首页与项目管理
4. 素材导入与整理
5. 文件浏览、选片与后期版本
6. 灵感库
7. 图像、视频与 Office 工具
8. 团片协作与可选组件
9. 备份、归档与数据安全
10. 设置、常见问题与反馈

## 发布前检查

- 将文档中的版本号更新为本次正式发布版本。
- 用非客户素材复核所有操作截图，避免出现客户姓名、项目名或原片。
- 明确提示“导入后删除源文件”的风险，并建议首次使用时关闭该选项。
- 对外分享前再次检查工作目录、邮件地址、文件路径和日志截图中的敏感信息。
- 若软件功能发生变化，以当前开发版界面和代码为准同步修订文档。
