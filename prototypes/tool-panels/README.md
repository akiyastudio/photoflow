# PhotoFlow 工具面板 HTML 原型

静态展示 PhotoFlow 的 16 个工具面板：其中 14 个来自当前可达入口，另外 2 个属于已有代码或功能、但入口不明显或尚未接入的能力。大多数任务只保留“准备、处理中、结果”三个状态；项目归属、复制确认和范围确认等必要决策步骤单独展示：

- 6 个导入面板
- 5 个媒体处理面板
- 3 个协作与管理面板
- 2 个隐藏与待补入口面板

“隐藏与待补入口”包括：没有任何界面跳转入口的 `VideoSplitView`，以及只在 Office 文件右键菜单中出现、目前没有独立面板的图片提取能力。

直接用浏览器打开 `index.html` 即可。面板内业务控件为纯展示；内容标题和点阵画布之间的 `PROTOTYPE · 状态预览` 按钮用于切换状态，属于原型查看器，不属于真实软件面板。所有任务执行状态统一使用同一种进度区域。
