# 视频处理组件

该组件为文件页“视频工具”菜单贡献“视频转码”和“视频切割”两个面板入口，并完整拥有编码 FFmpeg、转码、切割、裁剪、导入后处理与视频缩略图运行时。PhotoFlow Host 只负责授权输入/输出路径、任务调度、取消/暂停和项目发布语义。

时间线帧提取不属于本组件，由 `video-playback-mpv` 播放器组件通过 libmpv 提供。组件未安装或运行时校验失败时，依赖它的功能明确返回“视频处理插件不可用”，主程序不回退到内置编码 FFmpeg。

源码目录本身也是独立边界：私有 `requirements.txt`/`.venv`、FFmpeg 锁文件、完整 vendor 产物、对应源码与许可证归档、审计策略、构建脚本和 CI 工作流副本都位于本目录。执行 `npm run setup` 后，开发、测试和打包均不读取仓库根 `.venv`、`artifacts`、`media-runtime` 或构建脚本。
