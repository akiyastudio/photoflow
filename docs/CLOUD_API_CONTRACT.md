# 客户端与云端的接口边界

桌面客户端通过 HTTPS 使用独立部署的云服务。服务端实现、管理后台、部署说明、服务端测试和部署归档在私有项目维护，不是桌面构建输入。

## 客户端配置

`electron/cloud-config.cjs` 提供 `apiBaseUrl`、`ingestKey` 和更新渠道。服务地址和 `X-PhotoFlow-App` 应用标识随客户端分发，不能作为管理权限凭据。管理 Token、云平台 SecretId/SecretKey 和服务端环境变量不应出现在客户端配置中。

## 请求与隐私边界

| 请求 | 用途 | 客户端控制 |
| --- | --- | --- |
| `POST /v1/events` | 使用事件 | 受对应的自愿同意开关、允许事件集合及最小化字段限制 |
| `POST /v1/crashes` | 崩溃报告 | 受对应的自愿同意开关控制，发送前脱敏 |
| `POST /v1/feedback` | 用户主动反馈 | 由用户主动发送，与使用统计开关区分 |

具体载荷、允许事件和脱敏规则以 `electron/services/telemetry-service.cjs` 及客户端测试为准。队列在发送前重新检查同意状态；关闭开关或撤回同意后不得继续发送相应队列。

更新检查和发行工具使用的接口由各自调用代码维护。发行工具从外部取得管理凭据，不把凭据写入桌面安装包。

## 验证与维护

公开项目的 `npm run test:privacy` 验证客户端同意、脱敏和队列行为。服务端的隐私操作、管理鉴权、数据库集成、客户端事件一致性及部署包导入检查在私有服务端项目执行，不要求公开 CI 能读取私有源码。

保存期限、删除任务、部署地域和权利请求的实际执行状态必须由私有服务端的验收证据确认，不能由本文件或客户端实现推断。
