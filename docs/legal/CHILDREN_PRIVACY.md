# 照片流儿童个人信息保护规则

版本：2026-07-29

照片流不面向不满十四周岁的儿童提供产品或注册服务，但摄影师导入的婚礼、亲子、校园或活动素材可能包含儿童。

摄影师、影楼或其他实际决定处理目的和方式的用户应在处理前：

1. 以显著、清晰方式向监护人说明处理者身份、联系方式、目的、方式、信息种类、保存期限和权利行使方法。
2. 取得儿童父母或其他监护人的同意；涉及人脸身份识别时取得针对敏感个人信息的单独同意。
3. 仅处理实现摄影服务所必需的信息，不将儿童人脸用于无关的身份库、训练、营销画像或自动决策。
4. 严格限制项目目录访问，完成交付或目的实现后及时删除无须保留的身份分组、工作图和缓存。
5. 为监护人提供查询、更正、复制、删除和撤回同意的渠道。

如用户无法证明具有合法授权，不得启用儿童人脸身份识别。权利请求或问题可联系 akiyastudio@qq.com；与摄影项目素材有关的请求通常还应直接向负责该项目的摄影师或工作室提出。
