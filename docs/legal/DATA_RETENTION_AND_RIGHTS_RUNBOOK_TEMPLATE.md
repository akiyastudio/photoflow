本模板用于记录 CloudBase 实际环境、保存和删除任务，以及查询、更正、删除、复制/导出请求的操作证据。不得把仓库中的示例配置、集合名称或代码字段当成线上部署证明。

## 1. 公开政策基线

当前隐私政策和安装条款声明：

- 公测原始使用统计保留不超过 180 天；
- 崩溃报告在问题修复后 90 天内删除，且从接收起最迟不超过 1 年；
- 未验证删除机制前不得转为正式商用。

如实际系统无法满足该基线，应停止相关写入或限制发布并完成整改；不得通过修改本模板把不一致描述为已合规。

## 5. 定时清理任务设计与部署证据

CloudBase 官方的[云函数配置文件说明—触发器配置](https://docs.cloudbase.net/cli-v1/functions/configs#触发器配置)将触发器声明为 `name`、`type` 和 `config`，其中 `type` 为 `timer`、`config` 使用 Cron 表达式。官方示例包含七段表达式。下面只是待审批示意，不表示仓库或线上已部署：

```json
}
```

### 幂等、批次和审计要求

1. 每次运行生成唯一 `runId`，固定本次 `cutoff`；重试使用同一删除条件，不因重复执行删除保留期内记录。
2. 使用稳定排序和游标分批查询；记录每批首尾游标、候选数、成功数、失败数和耗时，避免只处理平台默认第一页。
3. 删除前仅记录文档 ID 的不可逆摘要或数量，不把崩溃正文、反馈正文或安装 ID 写进清理日志。
4. 每批删除后用同一截止条件复查剩余数量；超时后由下一次运行继续，不能把部分成功记为整次成功。
5. 审计日志至少包含任务版本、环境/地域标识、规则版本、开始/结束时间、`runId`、截止时间、批次、数量、错误码、重试和操作者；保存期限及访问权限由用户填写。
6. 任务失败或过期记录仍存在时触发告警和工单；手工补偿必须复用相同边界并保留双人复核。

### 首次上线和周期验收

- 在隔离测试集合放入“未到期、刚到期、超期、已修复、未修复、缺字段、同时间不同 `_id`”记录；执行两次并证明幂等。
- 验证统计最早记录不超过 180 天；验证已修复崩溃在修复满 90 天后删除；验证任何崩溃最迟 1 年删除。
- 模拟分页、限流、超时、单条失败、日志写入失败和任务重入；保留告警及恢复证据。
- 首次生产运行先做只读盘点/预览，由两人复核候选数量后再允许删除。
- 每月抽样最早记录、最近成功日志和失败工单；每次函数、字段、索引、时区或政策变更后重新演练。

### 通用受理与身份核验

1. 通过公开渠道建单，记录请求类型、范围、时间和首响期限；不要要求用户在普通邮件中发送无必要的身份证件。
2. 按风险分级核验。服务端保存 `installId` 的 SHA-256（`installHash`），请求人可提供软件显示的安装 ID 以便在受控工具内计算并定位；不得在工单标题或普通日志公开原始安装 ID。
3. 核验材料应最小化、有访问期限和销毁规则。无法核验、涉及他人或有法定限制时，按内部 SOP 审批并说明理由。
4. 冻结与请求相关的自动修改（如适用），记录查询语句版本、操作者、结果数量和复核人。

### 查询/访问

- 以经核验的 `installHash` 及必要的时间/记录 ID 查询 `analytics_events`、`crash_reports` 和 `user_feedback`；核对人工导出、日志和备份范围。
- 双人复核导出内容，移除其他个人、凭据和内部安全信息；通过批准的安全渠道交付。
- 证据：请求工单、身份核验结论、查询条件哈希、结果数量、复核和交付回执。实际值：`[待填写]`。

### 更正

- 判断字段是可更正事实、用户主动反馈正文，还是不可改写的审计/统计记录；规则由用户/律师批准。
- 采用有前后值审计的受控操作，验证所有活跃副本；不能更正时说明理由并提供可行替代。
- 证据：变更审批、前后记录哈希、复查结果和答复。实际值：`[待填写]`。

### 删除

- 先生成候选清单和数量，经双人复核后删除主集合，并覆盖临时导出、失败队列和适用副本。
- 对备份采用到期销毁或隔离标记时，记录不能即时物理删除的原因、访问限制和最终销毁日期。
- 删除后以相同条件复查为零；不得把“已发起”当作“已删除”。
- 证据：批准、批次日志、删除前后计数、备份处置和用户答复。实际值：`[待填写]`。

### 复制/导出

- 定义机器可读格式、字段解释、分页完整性、大小上限和安全交付方式；导出应覆盖全部页面并记录完整性标志。
- 导出文件加密、设定短期有效期并在交付后按期销毁；密钥通过不同渠道传递。
- 证据：导出工具版本、查询快照时间、记录数、文件 SHA-256、交付回执和销毁日志。实际值：`[待填写]`。
