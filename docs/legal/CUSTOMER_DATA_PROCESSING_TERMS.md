# 照片流客户数据处理条款（影楼/摄影工作室版）

版本：2026-07-29

## 1. 角色

对于仅保存在客户设备和客户指定磁盘中的摄影素材，客户自主决定处理目的和方式，并负责履行个人信息处理者义务；照片流发布者默认无法访问该素材。对于运营者自主收集的内测统计和崩溃报告，运营者按照《隐私政策》承担相应责任。

## 2. 客户义务

客户应确保取得照片、视频、姓名、联系方式、备注、未成年人信息及人脸信息的合法处理依据；控制账号、设备和目录权限；配置合理保存期限；响应被摄者权利请求；不得将软件用于非法监控、身份库建设或歧视性自动决策。

## 3. 本地处理

照片流核心素材、缩略图、项目数据库和人脸特征默认在本机处理。客户主动使用网盘同步、远程桌面、邮件、GitHub反馈或其他第三方工具导致的数据传输不属于照片流自动上传。

## 4. 技术支持

需要发布者远程查看日志或样本时，双方应另行确认范围、目的、期限和传输方式。客户应优先提供去标识化样本，不得提供与故障无关的完整客户原片。支持结束后应按约定返还或删除材料。

## 5. 安全事件

双方发现可能影响摄影素材或个人信息的事件时，应及时通知对方，保留必要证据并配合调查、补救和依法通知。具体时限、责任和联系人应在采购或服务合同中补充。
