# 个人信息安全事件应急预案

版本：2026-07-29

## 分级与响应

1. 发现：监控云函数异常、数据库权限、泄露反馈、恶意请求和错误上传。
2. 遏制：轮换管理Token和服务端密钥，关闭受影响接口，撤销异常权限，保存证据。
3. 评估：确定数据种类、数量、人员范围、时间、原因和可能危害，特别标记人脸或儿童信息。
4. 修复：修补漏洞、删除异常数据、恢复最小权限、验证客户端脱敏及服务端规则。
5. 通知：达到法律要求时及时向主管部门和受影响个人告知事件、影响、已采取措施、个人防范建议和联系人。
6. 复盘：形成根因、时间线、证据、整改和复测报告；必要时重新开展影响评估。
