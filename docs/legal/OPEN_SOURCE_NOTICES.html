照片流开源软件与模型许可说明

版本：2026-08-04

软件内“设置 → 关于”列出了主要第三方软件、模型来源、版本、哈希及许可证链接。发行包还必须保留Electron/Chromium等组件随附的完整机器可读许可证。

特别注意：

  1. FFmpeg 7.1.1 与固定提交的 x264、x265 使用 GPL-2.0-or-later。构建启用照片流 H.264/H.265 转码需要的 x264、x265 外部组件，并禁用 xvid、Avisynth、rubberband、nonfree 和网络功能。每个二进制版本必须在同一腾讯云发布记录提供精确对应源码、构建参数、许可证与 SHA-256。
  2. 高级视频组件只接受 -Dgpl=false 的 LGPL-2.1-or-later libmpv；其链接的 FFmpeg 及传递依赖也必须保持 LGPL 兼容。组件归档保留对应源码、构建配置、许可证和哈希清单。
  3. HEIC/HEIF 解码使用 pi-heif 1.4.0。其 Python 代码为 BSD-3-Clause；该组件的 Windows 二进制包包含 LGPL-3.0 的 libheif 1.23.0 与 libde265 1.1.1。pi-heif 仍使用仅解码构建，不包含 HEIF 编码功能；FFmpeg 所使用的 x265 则按上一项单独提供对应源码和许可证。
  4. ONNX模型、训练数据和转换脚本分别适用其上游许可及使用限制。
  5. 照片流自主代码采用专有许可并保留所有权利，不属于开源软件；仓库根目录 LICENSE 不改变任何第三方组件原有的开源许可。
